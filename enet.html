Regole d’integrazione

Confini prima dei collegamenti.

Interfaccia e runtime sono distinti

Il codice di questa directory è statico. Le funzioni che richiedono account, database, modelli AI o nodi devono essere servite da API separate e documentate.

Un link non prova un servizio

I link aprono repository sorgente. Lo stato operativo si mostra solo con un controllo live del relativo endpoint; le capacità non collegate restano marcate come sperimentali o separate.
